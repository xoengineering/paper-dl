# paper-dl

Download papers for offline archives, from any source, with one command.

`paper-dl` will route each paper ID or URL to the `<site>-dl` gem that handles it:

- [arxiv-dl](https://github.com/xoengineering/arxiv-dl) for arxiv.org
- [jstor-dl](https://github.com/xoengineering/jstor-dl) for JSTOR's Early Journal Content, via the Internet Archive
- [hal-dl](https://github.com/xoengineering/hal-dl) for HAL, France's national open archive
- and more to come

In development. This version is a placeholder.
